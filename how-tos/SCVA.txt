• Option: modify yabridge to use Proton instead of Wine

yabridge https://archlinux.org/packages/extra/x86_64/yabridge/ uses by default Wine (a dependency), to use Proton instead, modify the yabridge-*-x86_64.pkg.tar.zst package, run:
⃝
sudo pacman -Swdd --noconfirm yabridge
a=/tmp/!/yabridge-*-x86_64.pkg
tar --one-top-level -xf $a.tar.zst -C /tmp/!
sed -i /wine/d $a/.BUILDINFO $a/.PKGINFO
sed -i 2cPATH=/run/media/a/8688e754-c2e4-40d1-a9c8-c205211ca8d9/pfx/drive_c/Program"' Files (x86)/Steam/steamapps/common/Proton - 'a_version/files/bin:\$PATH\nexport "PATH $a/usr/bin/yabridge-host.exe
tar -cf /tmp/!/.tar -C $a $(ls -A $a)
sudo pacman -U --noconfirm /tmp/!/.tar
rm -r /tmp/!
yabridgectl add /a_path/pfx/drive_c/'Program Files'/Steinberg/VSTPlugins
WINEPREFIX=/a_path/pfx yabridgectl sync
⏺

Instead of editing /usr/bin/yabridge-host.exe :
⃝
WINELOADER=/a_path/pfx/drive_c/'Program Files (x86)/Steam/steamapps/common/Proton a_version'/files/bin/wine qtractor
⏺
is also possible.

• Configure Qtractor

Qtractor, View, Buses..., Master - MIDI bus, Output Plugins, Add..., SOUND Canvas VA, OK, Close Buses, Track, Add Track..., MIDI, OK, Play, Stop, Play-head back to 0, Mixer, left click under the track, left click the track, monitor in Inputs of Mixer, Close Mixer, Track, Remove Track, OK,
option, save: File, Save, Name: e.g. SCVA, Directory: e.g. /home/username/Desktop, OK, Save, Close Qtractor

Track, Import Tracks, MIDI..., MIDI file(s), Play
